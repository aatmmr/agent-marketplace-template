# Agent Marketplace Guide

A template repository for building and maintaining a marketplace of AI-supporting assets (Skills, Agents, MCP configs)
packaged as [VS Code agent plugins](https://code.visualstudio.com/docs/agent-customization/agent-plugins).
Start with the [README.md](README.md) for the user-facing overview and install steps.

## Repository Structure

- `plugins/<plugin-name>/` — one folder per published plugin (`plugin.json`, `README.md`, `skills/`).
- `.github/plugin/marketplace.json` — the marketplace registry; every plugin must be listed here.
- `website/` — Vite single-page app that renders a searchable catalog from a generated manifest.

## Build & Manifest

Run these from the `website/` folder:

| Command | Purpose |
| --- | --- |
| `npm run generate` | Rebuild [website/src/data/manifest.json](website/src/data/manifest.json) and copy design assets. |
| `npm run dev` | Generate the manifest, then start the Vite dev server. |
| `npm run build` | Generate the manifest, then build the production bundle. |
| `npm run preview` | Preview the production build. |

The manifest is generated by [website/scripts/generate-manifest.js](website/scripts/generate-manifest.js)
by scanning `plugins/` and the marketplace registry. **Always run `npm run generate` after adding or
editing a plugin, skill, or README** so the catalog stays in sync. There is no test or lint setup.

## Adding or Updating a Plugin

1. Create `plugins/<plugin-name>/` (lowercase kebab-case; folder name must match `plugin.json` `name`).
2. Add `plugin.json` following the [Agent Plugins spec](https://github.com/agentplugins/agent-plugins-spec/)
   and its [1.0.0 schema](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json). See existing
   examples for the fields in use: `$schema`, `name`, `description`, `version`, `author`, `repository`,
   `license`, `keywords`.
3. Add one or more skills under `skills/<skill-name>/SKILL.md` (see Skill Conventions below).
4. Write a comprehensive `README.md` (see README Requirement below).
5. Register the plugin in [.github/plugin/marketplace.json](.github/plugin/marketplace.json)
   with `name`, `source` (`./plugins/<plugin-name>`), and `description`.
6. Bump the plugin `version` whenever you publish changes.
7. Run `npm run generate` in `website/` to refresh the manifest.

## Skill Conventions

Skills follow the [Agent Skills format](https://agentskills.io/): a folder containing a `SKILL.md`
with YAML frontmatter, plus optional `flow/`, `template/`, `references/`, and `assets/` subfolders.

- `SKILL.md` frontmatter requires `name` and `description`; `name` must match the skill folder name.
- Write the `description` for discovery using the "Use when: …" pattern with concrete trigger phrases —
  this is what an agent reads to decide whether to load the skill (progressive disclosure).
- Keep the `SKILL.md` body actionable; link to bundled files in `flow/`, `template/`, and `references/`
  rather than inlining large content.

## README Requirement

Every plugin **must** maintain a comprehensive `README.md` following best practices.
Include, where applicable:

- **Title & summary** — what the plugin does and who it is for.
- **Installation** — marketplace registration snippet and the install-from-source alternative.
- **Included Skills** — a table linking each skill, with when to use it.
- **Quick Start** — example Copilot Chat prompts.
- **Input Requirements** — expected input files/frontmatter, if any.
- **Generated Deliverables** — outputs the plugin produces, if any.
- **Recommended Workflow** — step-by-step usage guidance.
- **Repository Structure** — folder/file layout of the plugin.
- **Maintaining the Plugin** — versioning and change-management notes.
